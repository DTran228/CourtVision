# Optional user study — not performed

Recruit 3–5 actual players/coaches with consent to use their feedback. Record
anonymous participant IDs, relevant experience and clip permissions. Do not put
names or private footage into Git. Participation is not assumed.

Use matched but different clips for manual and assisted review; counterbalance
order across participants. Reusing the same clip risks a memory advantage. Keep
the evaluation labels independent from participants' corrections and app reviews.

Raw CSV columns: participant_id, condition, order, clip_sha256,
recording_session_id, start_time, finish_time, review_seconds, labeled_attempts,
missed_attempts, incorrect_outcomes, corrections, notes. Measure full watch/review/
correction time, including failures. State denominators and report individual
paired results plus median/range. With this small sample, treat findings as a
formative study rather than a general population impact claim.

No participants, timings or satisfaction values have been invented. Current
status: pending participant availability and independently verified labels.
